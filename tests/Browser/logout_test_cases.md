# Skenario Pengujian Otomatis (Automatic Test Cases) - Fitur Logout Pengguna

Dokumen ini berisi detail skenario pengujian otomatis untuk **Fitur Logout Pengguna** di OceanCare yang diimplementasikan menggunakan Laravel Dusk pada berkas [LogoutTest.php](file:///c:/Users/ADVAN/Downloads/PROJEKPPLB-rheina/PROJEKPPLB-rheina/tests/Browser/LogoutTest.php).

| ID | Modul/Fitur | Test Case Scenario | Precondition | Steps | Input | Expected Result |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **TC-OUT-01** | Logout Pengguna | Pengguna dapat keluar dari sistem dengan menekan tombol Logout sebagai Volunteer. | Pengguna sudah login sebagai volunteer. | 1. Masuk ke halaman dashboard volunteer `/volunteer/dashboard`<br>2. Tunggu tombol logout muncul di navbar<br>3. Klik tombol Logout | Klik tombol logout (`form[action*="logout"] button`) | Berhasil dialihkan ke landing page (`/`) dan sesi terputus (guest). |
| **TC-OUT-02** | Logout Pengguna | Pengguna dapat keluar dari sistem dengan menekan tombol Logout sebagai Organizer. | Pengguna sudah login sebagai organizer. | 1. Klik tombol Logout | Klik tombol logout (`form[action*="logout"] button`) | Berhasil dialihkan ke landing page (`/`) dan sesi terputus (guest). |
| **TC-OUT-03** | Logout Pengguna | Pengguna dapat keluar dari sistem dengan menekan tombol Logout sebagai Admin. | Pengguna sudah login sebagai admin. | 1. Masuk ke halaman dashboard admin `/admin/dashboard`<br>2. Tunggu tombol logout muncul di navbar<br>3. Klik tombol Logout | Klik tombol logout (`form[action*="logout"] button`) | Berhasil dialihkan ke landing page (`/`) dan sesi terputus (guest). |
| **TC-OUT-04** | Logout Pengguna | Pengguna tidak dapat mengakses kembali halaman dashboard setelah melakukan logout. | Pengguna sudah login dan kemudian logout. | 1. Login sebagai pengguna volunteer<br>2. Masuk ke dashboard volunteer<br>3. Klik tombol Logout di navbar<br>4. Setelah logout, coba navigasi langsung kembali ke `/volunteer/dashboard` | - Klik tombol logout<br>- Akses URL `/volunteer/dashboard` | Diarahkan ke halaman login (`/login`) saat mencoba mengakses dashboard kembali. |
| **TC-OUT-05** | Logout Pengguna | Pengguna tamu (unauthenticated) dialihkan ke `/login` jika mencoba mengirimkan request logout (POST `/logout`). | Pengguna dalam keadaan belum masuk (guest). | 1. Kunjungi halaman login `/login` (untuk mengambil token CSRF)<br>2. Kirim form request POST ke `/logout` secara manual menggunakan script | Kirim request POST ke `/logout` | Otomatis dialihkan ke halaman login (`/login`) karena route dilindungi oleh middleware auth. |
