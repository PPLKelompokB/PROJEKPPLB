# Skenario Pengujian Otomatis (Automatic Test Cases) - Fitur Manajemen Profil Pengguna

Dokumen ini berisi detail skenario pengujian otomatis untuk **Fitur Manajemen Profil Pengguna (Profile)** di OceanCare yang diimplementasikan menggunakan Laravel Dusk pada berkas [ProfileTest.php](file:///c:/Users/ADVAN/Downloads/PROJEKPPLB-rheina/PROJEKPPLB-rheina/tests/Browser/ProfileTest.php).

| ID | Modul/Fitur | Test Case Scenario | Precondition | Steps | Input | Expected Result |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **TC-PROF-01** | Manajemen Profil | Halaman profil dapat diakses dan menampilkan detail data pengguna dengan benar. | Pengguna sudah login. | 1. Kunjungi halaman `/profile`<br>2. Tunggu teks "Profile" termuat<br>3. Periksa kecocokan data pengguna yang tampil di layar | Navigasi ke URL `/profile` | Menampilkan Nama ("Rheina Volunteer"), Email ("rheina@mail.com"), Telepon ("081234567890"), dan Lokasi ("Surabaya, Indonesia") sesuai database. |
| **TC-PROF-02** | Manajemen Profil | Pengguna dapat mengedit nama, email, nomor telepon, dan lokasi dengan data valid. | Pengguna sudah login. | 1. Kunjungi halaman edit profil `/profile/edit`<br>2. Tunggu form profil muncul<br>3. Isi Nama dengan "Rheina Updated"<br>4. Isi Email dengan "rheina.updated@mail.com"<br>5. Isi Telepon dengan "08999999999"<br>6. Isi Lokasi dengan "Jakarta, Indonesia"<br>7. Klik tombol submit form profil | - Nama: `Rheina Updated`<br>- Email: `rheina.updated@mail.com`<br>- Telepon: `08999999999`<br>- Lokasi: `Jakarta, Indonesia` | Berhasil memperbarui data, redirect kembali ke `/profile`, muncul pesan sukses "Profil berhasil diperbarui.", serta data yang diperbarui berhasil ditampilkan. |
| **TC-PROF-03** | Manajemen Profil | Pengguna dapat mengganti foto profil dengan mengunggah gambar baru yang valid. | Pengguna sudah login. | 1. Kunjungi halaman edit profil `/profile/edit`<br>2. Tunggu form muncul<br>3. Unggah berkas gambar valid (PNG/JPG/JPEG, < 2MB)<br>4. Klik tombol submit form profil | Berkas foto profil: file gambar dummy `profile_photo.png` | Foto profil berhasil diunggah, redirect ke `/profile`, dan muncul pesan sukses "Profil berhasil diperbarui.". |
| **TC-PROF-04** | Manajemen Profil | Menguji kegagalan pembaruan profil saat nama dan email dikosongkan. | Pengguna sudah login. | 1. Kunjungi halaman edit profil `/profile/edit`<br>2. Kosongkan field nama dan email<br>3. Submit form profil (melewati validasi native browser HTML5) | - Nama Lengkap: kosong<br>- Email: kosong | Gagal memperbarui, tetap berada di halaman `/profile/edit` (redirect back), dan memunculkan pesan error validasi "Nama lengkap wajib diisi." dan "Email wajib diisi.". |
| **TC-PROF-05** | Manajemen Profil | Pengguna tidak dapat menggunakan email yang sudah terdaftar pada pengguna lain. | Pengguna lain sudah terdaftar di database dengan email `other@mail.com`. | 1. Kunjungi halaman edit profil `/profile/edit`<br>2. Ubah field email menjadi "other@mail.com"<br>3. Klik tombol submit form profil | - Email: `other@mail.com` | Gagal memperbarui, tetap berada di halaman `/profile/edit`, dan menampilkan pesan kesalahan "Email sudah digunakan oleh pengguna lain.". |
| **TC-PROF-06** | Manajemen Profil | Menguji validasi sisi klien (JavaScript) jika format berkas tidak sesuai (.txt) atau ukuran berkas terlalu besar (> 2MB). | Pengguna sudah login. | 1. Kunjungi halaman edit profil `/profile/edit`<br>2. Coba unggah file dengan format tidak valid (.txt)<br>3. Coba unggah file dengan ukuran lebih dari 2MB (2.1 MB) | - Berkas 1: `profile_text.txt`<br>- Berkas 2: `profile_large.jpg` (> 2MB) | Muncul pesan error validasi client-side di bawah foto, berkas input dikosongkan secara otomatis:<br>- Kesalahan format: "Only JPG, JPEG, and PNG formats are allowed."<br>- Kesalahan ukuran: "Image size cannot exceed 2 MB." |
